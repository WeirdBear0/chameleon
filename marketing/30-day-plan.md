# 30-day plan
Week 1: Launch application page + consent form; build org/advisor target list (public directories) in private CRM; finalize templates; get board sign-off on guardrails.
Week 2: Send 100 advisor emails + 20 program partnership asks; post 3x on LinkedIn/IG from the org account; start referral link for current directors.
Week 3: Follow-ups; give 2–3 club meeting/webinar pitches; run intro calls with applicants; target uncovered states.
Week 4: Review KPIs, double down on best channel; onboard first cohort; publish a "meet our new directors" post (with consent).

KPIs (month 1): 150 adult/org touches, 15% reply, 25 applications, 10 interviews, 5 directors onboarded.
